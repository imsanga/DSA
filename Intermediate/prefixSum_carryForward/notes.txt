1. CARRY FORWARD
-------------------------

Definition:
Carry information from previous elements while traversing the array.

Core Idea:
Instead of recalculating previous answers, keep updating one running variable.

2. PREFIX SUM
-------------------------

Definition:
* Store cumulative sum till every index
* Carry Forward is a technique, Prefix Sum uses carry forward technique where it carries sum of previous elements

Formula: prefix[i] = prefix[i-1] + arr[i]

Meaning: prefix[i] = sum of elements from index 0 to i

Example:

Array: 2 4 6 1 3

Prefix: 2 6 12 13 16

Building Prefix:

prefix[0] = arr[0];

for(int i = 1; i < n; i++) prefix[i] = prefix[i-1] + arr[i];

Time: O(N)

Space: O(N)

Think Prefix Sum When You See:

✔ Sum(L,R)
✔ Multiple range queries
✔ Continuous subarray sum
✔ Cumulative sum
✔ Running total
✔ Frequency till index
✔ Count in a range

Common Problems:

• Range Sum Query
• Subarray Sum Equals K
• Count Odd/Even in Range
• Prefix Frequency Array
• 2D Prefix Sum (Matrix)
• Difference Array
• Equilibrium Index
• Pivot Index
