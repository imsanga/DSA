logarithm - How many time the exponent is multiplied with the base to get the result

formula
-> b^x = y
log base b on both sides
log_b b^x = log_b y
-> x = log_b y
ex: 3 = log_2 8 // why base 2? computers use 0 and 1(binary)

-> log(ab) = log a + log b
-> log(a/b) = log a - log b
-> log(a^k) = k log a
-> log_b b^x = x
ex: log_2 2^8 = 8
