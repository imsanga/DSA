explanation
i = i * 2
calc:
1,2,4,8,16,32,64... = n
2^0,2^1,2^2,...,2^k = n
2^k = n
k = log₂ n

i = i * 3
calc:
1,3,9,27... = n
3^0,3^1,3^2,...,3^k = n
3^k = n
k = log₃ n

--------------
i = i / 2  → O(log₂ N)
i = i / 3  → O(log₃ N)
i = i / k  → O(logₖ N)

i = i / 2
calc: n is 100
100,50,25,12,6,3,1
N, N/2, N/4, N/8,.. = 1
N, N/2^1, N/2^2, N/2^3,...,N/2^k = 1
n / 2^k = 1
n = 2^k
k = log₂ n

--------------
i = i + 2  → O(N)
i = i + 3  → O(N)
i = i + k  → O(N)

i = i - 2  → O(N)
i = i - 3  → O(N)
i = i - k  → O(N)

i = i + 2
calc:
1,3,5,7,9,11,... = n
1 + 2*0, 1 + 2*1, 1 + 2*2, ..., 1 + 2*k = n
1 + 2k = n
2k = n - 1
k = (n-1)/2
k = n

i = i - 2
calc: n is 100
100,98,96,94,92... = 1
n,n-2,n-4,n-6... = 1
n,n-2*1,n-2*2,n-2*3,...,n-2k = 1
n - 2k = 1
n - 1 = 2k
k = (n-1)/2
k = n

--------------
i² <= N → O(√N) || O(N^(1/2))
i³ <= N → O(∛N) || O(N^(1/3))
i^K <= N → O(ᵏ√N) || O(N^(1/K))

--------------
* Insertion/deletion at the beginning of an array is O(N), because the existing elements need to be shifted.

* exponent formulas
a^m × a^n = a^(m+n)
a^m / a^n = a^(m-n)
(a^m)^n = a^(m×n)
