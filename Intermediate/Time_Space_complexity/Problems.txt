problem 1:

int a = 0;
for (int i = 0; i < N; i++) {
    for (int j = N; j > i; --j) {
        a += i + j;
    }
}

soln: O(N^2)

problem 3:

int count = 0;

while (N > 0) {
    count++;
    N /= 3;
}

soln: O(log(N)) {Base 3}
note:
--> If the variable decreases by a fixed amount (N--, N = N - 5), the complexity is O(N).
--> If the variable decreases by a fixed factor (N = N/2, N = N/3, N = N/k), the complexity is O(log N).

problem 7:

static void solve(int N, int M) {
    for (int i = 1; i <= N; i++) {
        if (N % i == 0)
            System.out.println(i);
    }

    for (int i = 1; i <= M; i++) {
        if (M % i == 0)
            System.out.println(i);
    }
}

soln: O(N+M)
