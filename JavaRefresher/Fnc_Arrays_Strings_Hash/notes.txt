Method (Function)

Definition:
A method is a block of code that performs a specific task.

Syntax:
returnType methodName(parameters) {
    // code
    return value;
}

void → Returns nothing
return → Sends a value back to the caller

Benefits:
* Code reuse
* Better readability
* Easier maintenance
* Easier testing

extras:
* floor() → rounds down (towards negative infinity).
* ceil() → rounds up (towards positive infinity).

Arrays -- it is used to store multiple values of the same data type.
---------
1D Array
---------
• Stores data in a single row.
• Syntax: 
    int[] arr = new int[3];
    int[] arr = new int[] {10,20,30};
    int[] arr = {10,20,30};
    int[] arr = new int[0]; // empty array
• Access: arr[i]

2D Array
---------
• Stores data in rows and columns.
• Think of it as an array of arrays.
• Syntax:
      int[][] arr = {
          {1,2,3},
          {4,5,6}
      };
• Access: arr[row][column]

Traversal
---------
1D  -> One loop
2D  -> Nested loops

note:
--> transpose of matrix = columns * rows
--> use .equals instead of == for wrapper classes

Common Methods
--------------
Arrays.toString(arr1) // 1d array
Arrays.equals(arr1, arr2) // 1d array
Arrays.fill(arr, 5); // fills the array (eg: fills with element 5 in all index)
Arrays.copyOf(arr, 2); // copys the part of array (eg: copy arr of 2 elements)
Arrays.binarySearch(arr, 30) // Searches for an element in a sorted array and returns its index
Arrays.asList(arr) // it converts array to list

Arrays.deepToString(arr1) // 2d array
Arrays.deepEquals(arr1, arr2) // 2d array

ArrayList
---------
• Dynamic array.
• Size grows and shrinks automatically.
• Stores objects (Integer, String, etc.).
• Internally implemented using an array.

Common Methods
--------------
add(element)                        // Create / append element
get(index)                          // Read element
set(index, value)                   // Update element
remove(index)                       // Delete element at index
size()                              // Number of elements
contains(element)                   // Checks whether element exists
clear()                             // Removes all elements
isEmpty()                           // Checks whether list is empty
indexOf(element)                    // First occurrence index (-1 if absent)
lastIndexOf(element)                // Last occurrence index (-1 if absent)
remove(Integer.valueOf(element))    // Removes first matching element by value

Traversal
---------
for loop
for-each loop

Array
-----
Fixed size
length

ArrayList
---------
Dynamic size
size()

2D ArrayList
------------

Definition:
An ArrayList of ArrayLists.

Syntax:
ArrayList<ArrayList<Integer>> matrix = new ArrayList<>();

Access:
matrix.get(row).get(column)

Add Row:
matrix.add(new ArrayList<>());

Add Element:
matrix.get(row).add(value);

Traversal:
Two loops or nested for-each loops.

String
------
• Sequence of characters.
• Immutable.
• Uses double quotes.

Declaration
-----------
String s = "Java";

Important Methods
-----------------
length()
charAt(index)
substring(beginIndex)
substring(beginIndex, endIndex)
equals(anotherString)
equalsIgnoreCase(anotherString)
contains(str)
indexOf(ch)
toUpperCase()
toLowerCase()
startsWith(prefix)
endsWith(suffix)

Comparison
----------
==       -> compares references
equals() -> compares content

Traversal
---------
for(int i = 0; i < s.length(); i++) s.charAt(i);

Remember
--------
Array: arr.length

String: str.length()

StringBuilder
-------------
• Mutable sequence of characters.
• Used for frequent string modifications.
• Faster than String for concatenation.

Creation
--------
StringBuilder sb = new StringBuilder();

Common Methods
--------------
append(value)
insert(index, value)
delete(startIndex, endIndex)
deleteCharAt(index)
replace(startIndex, endIndex, "text")
reverse()
charAt(index)
setCharAt(index, 'c')
length()
toString()

Difference
----------
String        -> Immutable
StringBuilder -> Mutable

Use StringBuilder when:
-----------------------
✔ Repeated concatenation
✔ String reversal
✔ Character replacement
✔ Building large strings efficiently

HashSet
-------
• Stores unique elements.
• Does not allow duplicates.
• No indexes.
• No guaranteed order.
• Uses hashing internally.

syntax
-------
HashSet<Integer> hs = new HashSet<>();

Common Methods
--------------
add()
remove()
contains()
size()
clear()
iSEmpty()

Traversal
---------
for-each loop

Applications
------------
✔ Remove duplicates
✔ Detect duplicates
✔ Fast lookup
